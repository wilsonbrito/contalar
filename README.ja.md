# Contalar

[English](README.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · **日本語**

> 家計の支払い管理を、スプレッドシートなしで。あなた自身のパソコンで動きます。アカウント不要、クラウド不要、サブスクリプション不要。

Contalar（ポルトガル語の _contas_「支払い・請求」と _lar_「家庭」から）は、毎月支払うべきものと、すでに支払ったものを管理する小さなウェブアプリです。毎月のスプレッドシートの代わりになります。毎月繰り返す支払いは自動で作られ、実際の金額を入力して **Enter** を押すだけで「支払い済み」になります。

![月次ビュー](docs/images/month.png)

## 機能

- **月次ビュー**：その月のすべての支払いを、状態（支払い済み・未払い・期限切れ）、サマリーカード、状態フィルター、カテゴリー別の合計とともに表示します。実際の金額を入力して **Enter** を押すと支払い済みになります。
- **固定費**：家賃、電気代、インターネットなどは、見積もり金額（前回支払った金額）で毎月自動的に作成されます。請求書が届いたら金額を直すだけです。
- **分割払い**：N回払いの購入は、毎月N件の支払いとして登録されます（`3/10`）。
- **年間概要**：月ごとの支払い済み／未払いの比較、12月までの見通し、カテゴリー×月のヒートマップを備えた年間ダッシュボードです。
- **ローカルでプライベート**：データはお使いのパソコン内の SQLite ファイルに保存されます。サーバーは `localhost` でのみ待ち受け、アプリは外部へ通信しません。
- **バックアップ**：データベースを毎日コピーし、任意でプライベートな git リポジトリへ送信できます。

![年間概要](docs/images/overview.png)

## 仕組み

アプリには3つの画面があります。**現在、画面表示はブラジル・ポルトガル語です**（[制限事項](#制限事項)を参照）。次の表で名称を対応づけます。

| 画面       | アプリ内の表示  | 用途                                                 |
| ---------- | --------------- | ---------------------------------------------------- |
| 月次ビュー | _Contas do mês_ | 支払いの消込、単発・分割払いの追加、月の全体像の確認 |
| 年間概要   | _Visão geral_   | 1年間の全体像                                        |
| 固定費     | _Contas fixas_  | 毎月繰り返す支払いの登録                             |

### ある月の流れ

1. **最初に一度だけ：** 固定費（_Contas fixas_）を登録します。名前、見積もり金額、支払日、カテゴリーを設定します。
2. **月を開きます。** 各固定費が見積もり金額で表示されます。同じ月を何度開いても、重複して作られることはありません。
3. **請求書が届いたとき、または支払ったとき：** 実際の金額を入力して **Enter** を押します（または *Pagar*＝支払い をクリック）。支払日の初期値は今日で、変更できます。_Salvar_（保存）は、支払い済みにせず金額だけを保存します。
4. **単発・分割払いの購入：** _Nova conta_（新しい支払い）を使います。「parcelas」（分割回数）を2以上にすると、毎月1件ずつ作成され、`n/N` と表示されます。
5. **年間概要を見て**、お金の行き先と今後の月の見通しを確認します。

![固定費](docs/images/recurring.png)

### 知っておくと便利なこと

- **状態**は自動で判定されます。支払日があれば _Pago_（支払い済み）、未払いで支払期限を過ぎていれば _Atrasado_（期限切れ）、それ以外は _Pendente_（未払い）です。
- **固定費から作られた支払いを削除**すると、その月の分だけが消えます。固定費自体は他の月で引き続き有効です。固定費そのものを削除しても、すでに作成された支払いは残ります。
- **固定費を編集**すると、未払いの将来分（金額・名前・カテゴリー）も更新されます。ただし、手動で金額を調整したものは除きます。支払日の変更は新しい月にのみ適用されます。
- **見通し：** 今年の年間概要を開くと、残りの月の固定費が見積もり金額で作成され、先の1年を見渡せます。
- 金額は丸め誤差が出ないよう整数の**セント単位**で、日付は `YYYY-MM-DD` 形式で保存されます。

## クイックスタート

必要なもの：**Node.js 22.17 以上**、および `bash`、`curl`、`lsof`（macOS または Linux。Windows では WSL を使用してください）。

```sh
git clone https://github.com/wilsonbrito/contalar.git
cd contalar
./iniciar.sh
```

このスクリプトは、依存関係のインストール、データベースの作成、ビルド、<http://localhost:3000> での起動、ブラウザの起動までを行います。停止は `Ctrl+C` です。別のポートを使うには `PORT=4000 ./iniciar.sh` としてください。

### デモデータで試す

自分の支払いを入力する前に、まず触ってみたい方は、架空の家庭のデータを読み込めます。

```sh
npm install
npm run demo        # 架空の家庭の demo.db を作成
npm run demo:dev    # demo.db を使ってアプリを起動
```

`demo.db` は実際のデータベース（`local.db`）とは別のファイルです。デモ用スクリプトは `local.db` には一切触れません。

## バックアップ

アプリは起動するたびに、`backups/` にデータベースの整合性のあるコピーを作成します（`local-YYYY-MM-DD.db`、1日1つ、直近30件を保持）。復元するには、アプリを止めてバックアップを `local.db` に上書きコピーしてください。

パソコンの外にもコピーを残したい場合は、`backups/` をリモート付きの**プライベート**な git リポジトリにします。すると `iniciar.sh` が起動後に `scripts/enviar-backup.sh` を実行し、新しいバックアップをコミットして push します（前回の送信に失敗していた場合は再試行します）。

```sh
cd backups
git init -b main && git add -A && git commit -m "first backup"
gh repo create my-contalar-backups --private --source=. --push   # または任意のプライベートなリモート
```

> **このリポジトリは必ずプライベートにしてください。** データベースにはあなたの家計情報がすべて含まれています。自動送信を止めるには `SEM_ENVIO_BACKUP=1` を設定します。

## プライバシー

- データは `local.db` と `backups/` にあり、どちらも git の管理対象外です。
- サーバーは `127.0.0.1` でのみ待ち受けます。ネットワーク上の他の機器からはアクセスできません。
- アカウントなし、テレメトリなし、外部通信なし（CDN、外部フォント、アナリティクスを使っていません）。

## 制限事項

- **画面表示はブラジル・ポルトガル語**で、通貨はブラジル・レアル（`R$`）で表示されます。画面の翻訳と他の通貨への対応は、最も歓迎する貢献です。
- **1つの家庭が1台のパソコンで使う**ことを想定しています。ログインや複数ユーザーには対応していません。
- 管理するのは支払う費用のみです。収入、予算、投資は対象外です。
- macOS で動作を確認しています。Linux でも動くはずですが、Windows は未確認です（WSL を使用してください）。

## 開発

```sh
npm install
cp .env.example .env     # DATABASE_URL=local.db
npm run db:push          # テーブルの作成・更新
npm run dev              # http://localhost:5173
npm run check            # 型チェック
npm test                 # ユニットテスト（日付・分割払い・集計・バックアップ）
```

| パス                    | 内容                                        |
| ----------------------- | ------------------------------------------- |
| `src/lib/financeiro.ts` | 純粋なロジック：日付、状態、分割払い、集計  |
| `src/lib/server/db/`    | スキーマ（Drizzle）、クエリ、バックアップ   |
| `src/routes/`           | 画面：`/`（月次）、`/fixas`、`/visao-geral` |
| `scripts/`              | `demo.ts`（架空データ）、`enviar-backup.sh` |
| `iniciar.sh`            | ワンコマンドの起動スクリプト                |

**技術スタック：** SvelteKit 3 · TypeScript · Tailwind CSS 4 · Drizzle ORM + better-sqlite3 · Vitest
